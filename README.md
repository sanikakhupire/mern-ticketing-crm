# MERN Ticketing CRM

A full-stack Customer Relationship Management (CRM) / ticketing system with role-based
dashboards for **Admin**, **Employee**, and **Customer**, built using the MERN stack.

This is a rebuild of an earlier PHP/Flask CRM project, redesigned with production-grade
patterns: JWT authentication, real-time notifications, file uploads, analytics, and CI/CD.

## Tech Stack

- **Frontend:** React (Vite) + Tailwind CSS
- **Backend:** Node.js + Express
- **Database:** MongoDB + Mongoose
- **Auth:** JWT (access + refresh tokens)
- **Real-time:** Socket.io
- **File Uploads:** Multer + Cloudinary
- **Charts:** Recharts
- **Validation:** Zod
- **Testing:** Jest, Supertest, React Testing Library
- **Deployment:** Vercel/Netlify (frontend), Render/Railway (backend), MongoDB Atlas
